# 第六周：ETTh1 序列窗口与油温预测基线

本周只做**单步序列预测**，不使用 RNN 或 LSTM。

任务是：在某个时刻已经看到了过去 24 小时的变压器油温 `OT`，预测紧接着的下一小时 `OT`。每一条样本均遵守：输入是当时已经真实观测到的历史；目标是当时尚未知、之后才实测到的下一小时油温。

## 运行

在 `week06/` 目录中执行：

```powershell
python -m pip install -r requirements.txt
python run_windows.py
python run_baselines.py
```

本次运行环境：Python 3.14.7、NumPy 2.5.3、pandas 3.0.6、scikit-learn 1.9.1、matplotlib 3.11.2。

## 数据与固定设置

- 数据：`data/ETTh1.csv`，来自 [ETDataset 官方仓库](https://github.com/zhouhaoyi/ETDataset/tree/main/ETT-small) 的小时级 `ETTh1`。
- 实践一：取前 12 小时的 `OT`，比较 `L=3` 和 `L=5`。
- 正式实验：只取前 14,400 小时，时间从 2016-07-01 00:00 到 2018-02-20 23:00。
- 正式窗口长度：`L=24`。输入列从旧到新排列，最后一列是最近一次观测。
- 目标：预测窗口后紧接着的一小时油温，目标油温保持原始尺度。
- 时间划分依据是**目标时间**：训练目标到 2017-06-26 00:00 前；验证为 2017-06-26 00:00 至 2017-10-24 00:00 前；测试为 2017-10-24 00:00 至 2018-02-21 00:00 前。
- 结果样本数：训练 8,616 条，验证 2,880 条，测试 2,880 条。首条验证目标虽然属于验证期，但其 24 小时真实历史来自 2017-06-25，这是预测时已知的信息，可以使用。

## 实践一：窗口怎样构造

`make_windows(series, L)` 返回：

- `X`：每行连续 `L` 个历史油温；
- `y`：每行窗口紧接着的下一小时油温；
- `target_index`：该目标在原始序列中的下标。

若序列长度为 `N`，能构造的样本数为 `N-L`。本次短序列 `N=12`：

| 窗口长度 | 样本数 | 首条输入下标 | 首条目标下标 |
|---:|---:|---|---:|
| 3 | 9 | 0–2 | 3 |
| 5 | 7 | 0–4 | 5 |

例如 `L=3` 的首条样本：输入是 2016-07-01 00:00、01:00、02:00 的油温 `[30.531, 27.787001, 27.787001]`，目标是 03:00 的 `25.044001`。预测发生在 03:00 前，因此三个输入都已获得，03:00 的真实值只用于后来训练或评价。

前 12 小时油温不是单调变化：先由 30.531 降到 21.174，之后又局部回升。窗口保存这种连续的升降历史；`L` 从 3 改为 5 后，单条输入更长，但可开始预测的时刻更晚、总样本数更少。实际记录见 `results/window_examples.csv`。

## 三种基线与调参路线

| 模型 | 预测方式 | 是否从训练数据学习参数 |
|---|---|---|
| `last_value` | `ŷ[t] = OT[t-1]` | 否 |
| `window_mean` | 预测最近 24 个油温的均值 | 否 |
| `lag_linear` | 标准化 24 个滞后值后，拟合线性回归 | 是 |
| `ridge_tuned` | 标准化 24 个滞后值后，拟合 Ridge | 是 |

选择 Ridge 路线，是因为 24 个相邻滞后值通常彼此相关；Ridge 的 `alpha` 对权重加入 L2 约束，可观察“轻度约束、中等约束、较强约束”是否改善未见时段表现。候选为 `0.1、1、10`。每个模型只在训练窗口上 `fit`；标准化器也只在训练窗口上学习均值和标准差，验证/测试只调用同一管道的 `predict`。

## 调参结果与过拟合检查

`tuning.csv` 记录普通滞后线性回归参照和三组 Ridge 候选；`rmse_gap = val_rmse - train_rmse`。

| 配置 | 训练 RMSE | 验证 RMSE | 验证−训练 |
|---|---:|---:|---:|
| lag_linear | 1.043134 | 0.910183 | -0.132952 |
| Ridge α=0.1 | 1.043135 | 0.910179 | -0.132956 |
| Ridge α=1 | 1.043170 | **0.910172** | -0.132999 |
| Ridge α=10 | 1.045884 | 0.912002 | -0.133881 |

因此按“验证 RMSE 最小”的规则选 `alpha=1`，模型名为 `ridge_tuned`。它只比普通线性回归低约 `0.000011` RMSE，实际差别非常小；选择它是严格遵守验证集规则的结果，不应夸大为明显改善。

这轮比较没有显示“训练误差持续降低而验证误差变坏”的明显过拟合迹象：三个 Ridge 配置的验证 RMSE 都低于训练 RMSE。更合理的解释是训练期和验证期的油温波动/工况不同，不能仅据这一轮结果断言模型完全不存在过拟合。`alpha=10` 时训练与验证 RMSE 都变差，说明过强约束开始损失拟合能力。若继续实验，可在 `0.1` 到 `10` 附近增加更密的候选值，并检查更多滚动时间段。

## 最终评价

最终按验证 RMSE 在四种方法中选择总体最优；同分时按任务给定顺序处理。`ridge_tuned` 的验证 RMSE 为 0.910172，因此被标记为 `selected=True`。

| 模型 | 验证 RMSE | 测试 MAE | 测试 RMSE | 最终选定 |
|---|---:|---:|---:|---|
| last_value | 0.925271 | 0.420152 | 0.592978 | 否 |
| window_mean | 1.879948 | 1.033188 | 1.342148 | 否 |
| lag_linear | 0.910183 | 0.422645 | 0.584538 | 否 |
| ridge_tuned | **0.910172** | 0.422733 | **0.584437** | 是 |

测试集只在配置和总体选择固定后评价一次，没有参与调参。所有逐条预测均带有原始 `target_index`、`target_time`、`y_true`、`y_pred`；程序会从保存后的 `predictions.csv` 重算 MAE/RMSE，再与 `metrics.csv` 核对。

## 图与一次真实预测的解释

1. `tuning_comparison.png`：横轴是普通线性回归与三组 Ridge 配置，纵轴是原始油温尺度 RMSE；蓝、橙柱分别是训练和验证结果。它不是训练轮次曲线。
2. `series_split.png`：横轴是日期，纵轴是原始尺度 `OT`；虚线分别是验证与测试起点，浅色区域标记构造第一条窗口所需的最初 24 小时历史。
3. `validation_predictions.png`：验证首周。上图横轴是时间，纵轴是原始尺度油温，黑线是真实值、彩线是四种预测；下图是同时间的 `HUFL` 原始尺度负载。`HUFL` 不属于本周模型输入，只作为事后观察线索。

以验证第一条预测（2017-06-26 00:00）为例：模型可使用 2017-06-25 00:00 至 23:00 的 24 个真实油温，最近油温为 20.752001；真实目标是 20.962999。四种预测分别为：最近值 20.752001、窗口均值 21.312125、滞后线性回归 20.899998、Ridge 20.903076。Ridge 在该时刻低估约 0.060，但比窗口均值更接近真实值。该时段附近 `HUFL` 从 9.980 升至 10.851，油温没有同步大幅上升；这与热惯性以及未观测环境、冷却状态等因素相容，但不能只凭两条曲线判定负载导致油温变化，更不能把单次较大误差当作故障证据。
